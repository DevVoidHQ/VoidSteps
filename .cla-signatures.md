# CLA signatures

The record of who has agreed to [CLA.md](CLA.md).

**This file is the record, not the pull request comment.** A comment is the
trigger: a contributor pastes the agreement line on their first PR. A maintainer
then adds a row here and commits it before merging.

The reason is evidentiary. A PR comment can be edited or deleted by its author,
and it lives only for as long as the repository stays on GitHub. A row in the
repository is timestamped by a commit the contributor does not control, travels
with the code, and survives the platform.

If this ever moves to automated tooling, the tool writes a file of this shape,
so signatures recorded here carry over.

## For maintainers

Before merging a first-time contributor's pull request:

1. Check they have commented the agreement line on that PR.
2. Add a row above: their handle, today's date in `YYYY-MM-DD`, and the PR number.
3. Commit it, then merge.

One row per person, not per pull request. The agreement covers everything they
contribute from that point on.
